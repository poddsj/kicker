# kickbot

Telegram-бот для очистки группы: команда `/kickall` выгоняет всех участников,
кроме админов, тебя и самого бота.

## Установка

1. `python -m venv .venv && source .venv/bin/activate`
2. `pip install -r requirements.txt`
3. `cp .env.example .env` — вписать `BOT_TOKEN` и свой `ADMIN_IDS`.
   Свой user_id — у @userinfobot.
4. Добавить бота в чат **админом с правом «Блокировать участников»**.
5. `python -m bot.main`

## Команды

- `/kickall` — выгнать всех, кто в базе (без подтверждения)
- `/stats` — сколько участников в кэше
- `/start` — справка

## Ограничение Bot API

Telegram не отдаёт список участников группы. Бот видит только тех, кто писал
или заходил при нём. `members.db` копит эти ID через middleware и
`chat_member`-хендлер. Чистка работает по накопленной базе: чем дольше бот
в чате — тем полнее покрытие.

## Кик vs бан

`ban_chat_member` + `unban_chat_member` = кик: человек вылетает, но может
вернуться по инвайту. Чистый `ban` оставит его в чёрном списке.
